# Data Science & Analytics

## 1. Structured Data vs Unstructured Data

| Structured Data | Unstructured Data |
|---|---|
| Data organized in a predefined format. | Data that does not follow a predefined format. |
| Has a fixed structure. | Has no fixed structure. |
| Organized in rows and columns. | Not organized in fixed rows and columns. |
| Follows a predefined schema. | Does not follow a predefined schema. |
| Usually stored in relational databases (SQL). | Often stored in file systems, data lakes, and object storage. |
| Easy to process and analyze using traditional tools. | Comparatively difficult to process and analyze. |
| Can be easily searched using structured queries. | Often requires specialized tools and techniques for searching and analysis. |
| Examples: student records, bank transactions, and employee data. | Examples: images, videos, audio, emails, and social media posts. |

## 2. KDD vs Data Mining

| KDD | Data Mining |
|---|---|
| Stands for Knowledge Discovery in Databases. | Refers to extracting useful patterns from data. |
| It is the complete process of discovering knowledge from data. | It is one of the steps in the KDD process. |
| It has a broader scope. | It has a narrower scope. |
| Includes data selection, preprocessing, transformation, data mining, and interpretation/evaluation. | Focuses on applying algorithms to discover patterns. |
| Aims to discover valid, useful, and understandable knowledge. | Aims to identify hidden patterns and relationships. |
| Produces evaluated and understandable knowledge. | Produces patterns, rules, and relationships. |
| Example: the complete analysis of supermarket transactions. | Example: discovering that customers who buy bread often buy butter. |
